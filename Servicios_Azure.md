# 5 Servicios Cognitivos de Azure y sus Usos

## 1. Computer Vision

**¿Qué hace?**  
Analiza imágenes y reconoce lo que aparece en ellas.

**Ejemplo de uso:**  
Identificar productos en una tienda o leer texto de una fotografía.

---

## 2. API de Face

**¿Qué hace?**  
Detecta y reconoce rostros en imágenes o videos.

**Ejemplo de uso:**  
Control de acceso mediante reconocimiento facial.

---

## 3. Inteligencia de Documentos

**¿Qué hace?**  
Extrae información de documentos como facturas, formularios o recibos.

**Ejemplo de uso:**  
Registrar automáticamente los datos de una factura sin escribirlos manualmente.

---

## 4. Servicios de Voz

**¿Qué hace?**  
Convierte la voz en texto y el texto en voz.

**Ejemplo de uso:**  
Transcribir una reunión o crear un asistente virtual que responda hablando.

---

## 5. Traductor

**¿Qué hace?**  
Traduce textos entre diferentes idiomas.

**Ejemplo de uso:**  
Traducir páginas web o mensajes para comunicarse con personas de otros países.
